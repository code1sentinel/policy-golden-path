      Send to Enact

      Download a copy on this device. Nothing is uploaded. Send to Enact turns control statements into testable Rego policy.

      Codify writes the catalog. Enact runs the checks. They share a file, not a server.

      1. Download the OSCAL catalog below.
      2. Open Enact (Pages app).
      3. Load that JSON as the catalog. See Using Codify with Enact.

      The catalog is this project's OSCAL file (a NIST format other GRC tools read). Library downloads are optional copies of accepted statements on this device.

      • OSCAL catalog (recommended)

        Use this when you want to hand the catalog to another GRC tool, or reopen this project later.

      • Excel

        Use this when you want a spreadsheet of every control for review in Excel.

      • CSV

        Use this when you need the same rows in a text file. Safe for Excel — cells cannot run formulas.

      • Conversion report

        Use this when you want a readable summary of what was converted and what still needs work.

      AI drafting

      Off

      Off unless you turn it on. Codify still drafts with rules. With AI on, you can also ask a model to draft a clause's controls, with your own API key or with Ollama on this machine (no key). Every AI draft is scored like any other, marked as drafted by AI, and stays a draft until you review it.

      What is sent. One clause per request: its text, its section heading and Codify's rule drafts for it. It goes straight from this browser to the provider you choose, under your account and that provider's terms. It does not pass through Codify, and your key stays in this browser.
      Do not send classified or sensitive text. Use AI drafting only for policy text your organisation allows you to send to this provider. If in doubt, leave it off: the rule drafts need no AI.
